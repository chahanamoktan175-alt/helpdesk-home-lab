# Help Desk Home Lab

A virtual IT environment built in VMware Workstation to practice real help desk work: Active Directory, user support, and ticketing.

## What I've Built So Far
- Windows Server 2022 domain controller (DC01) for the domain `lab.local`
- Static IP addressing, DNS, and an internet forwarder
- Snapshots after each stage, so I can restore the lab if something breaks

## In Progress
- DHCP, users, groups and departments in Active Directory
- Windows 10 client joined to the domain
- Group Policy and shared folders with permissions
- osTicket help desk with categories and SLAs
- 20+ simulated tickets and knowledge base articles

## Skills Demonstrated
- Windows Server and Active Directory setup
- Network configuration and troubleshooting (IP, DNS, ping tests)
- Clear technical documentation with screenshots

## Tools
VMware Workstation, Windows Server 2022, Windows 10, osTicket, GitHub
